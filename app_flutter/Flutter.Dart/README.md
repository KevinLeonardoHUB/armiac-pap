# App Flutter — ARMIAC

Aplicação móvel da PAP ARMIAC.

A app permite:

- ligar ao ESP32 através do Wi‑Fi local;
- enviar comandos HTTP para controlar a mão robótica;
- usar botões para controlar movimentos;
- usar comandos de voz em português.

## Comandos úteis

```bash
flutter pub get
flutter run
```

Antes de testar, liga o dispositivo à rede Wi‑Fi criada pelo ESP32: `ARMIAC_ESP32`.
