# Materiais e componentes

Lista baseada no relatório final da PAP.

## Componentes principais

- ESP32 - microcontrolador principal e rede Wi-Fi em modo Access Point.
- PCA9685 - controlador PWM para vários servomotores.
- Servomotores MG996R - movimento dos dedos e rotação do antebraço.
- Servo low profile - movimento do polegar.
- Fonte DC 6V 10A - alimentação dos servos.
- Cabos/extensões de servo.
- Peças impressas em 3D para a mão e antebraço.

## Software usado

- Arduino IDE para o firmware do ESP32.
- Visual Studio Code / Android Studio para a aplicação Flutter.
- Elegoo Cura / Ultimaker Cura para preparação das peças 3D.
- Canva para o logótipo e materiais gráficos.
